# Where Hercyna Stands Among Memory Benchmarks

This note compares Hercyna with public LLM and agent memory benchmarks across what each measures, whether it scores downstream decisions or recall/QA/task-completion, and whether its results can be rerun offline from shipped packs.

## What Hercyna Adds and What It Leaves Out

- **What Hercyna measures differently:** Existing benchmarks mostly ask whether an assistant or agent can answer a question, recall a needle, or complete an interleaved task. Hercyna isolates the memory system behind a blind four-method API (`reset`, `ingest`, `retrieve`, `close`), fixes the shared memory-side extractor/embedder model, and scores discrete agent decisions (`right`, `withheld`, `wrong`) above each decider's own full-history noise floor. Splitting withheld actions from wrong actions shows when a memory product only appears safe by staying silent (`Graphiti`) rather than retrieving usable facts.
- **Offline verifiable packs:** Every shipped cell stores text-free metrics, bootstrap summaries, manifests, health logs, and spend files checked by `bench verify`, with `configs/v2/excused_ingest_errors.json` pinning reference ingest errors (`Mem0: 2`, `Graphiti: 13`) and a `5%` cap preventing silent cherry-picking on outside packs.
- **Where existing benchmarks go further today:** LoCoMo tests human-verified multi-modal long dialogues; LongMemEval scales chat histories with curated QA across 500 questions; MemoryAgentBench tests incremental Test-Time Learning; MemBench distinguishes participation vs. observation and reflective memory; GoodAI LTM tests interleaved multi-task continual learning. Hercyna `v2` currently covers one synthetic chat track (`300` cases), `5` deciders, and exploratory offline cause diagnostics.
